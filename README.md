## 📌 About the Project

This project is a simple **Registration Form** created as a beginner-friendly web development project.

The form allows users to enter their personal information, select skills, choose a course and technology, upload certificates, and submit their details.

The main purpose of this project is to practice **HTML form elements and CSS styling**.

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/registration-form.git
```

### 2. Open the project folder

```bash
cd registration-form
```

### 3. Open `index.html`

You can open `index.html` directly in your browser.

You can also use **VS Code + Live Server** to run the project.

---

## 🌐 Deployment

This project can be deployed easily using **GitHub Pages**.

### Steps:

1. Upload `index.html` to your GitHub repository.
2. Go to **Settings**.
3. Open **Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Click **Save**.

Your website will be available at:

```text
https://YOUR-USERNAME.github.io/registration-form/
```
